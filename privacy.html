Privacy Policy — Shorts Studio

Last updated: 19 November 2026

Who uses this application

Shorts Studio is a private desktop application used only by its owner to manage the owner's own YouTube channels. It is not offered to the public.

What Google user data is accessed

With the owner's permission through Google OAuth, the application uses the YouTube Data API and YouTube Analytics API to: upload videos to the owner's channels and schedule their publication; set video titles, descriptions, thumbnails and localizations; read the list of the channel's own uploads; read and post comments on the channel's own videos; and read the channel's analytics.

How data is stored

All data, including OAuth tokens, stays on the owner's own computer. The application has no server and does not send Google user data to any third party. Data is not sold, shared, or used for advertising.

Limited Use

Shorts Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the application's data folder on the computer removes all stored data.

Contact

Questions can be sent through the owner's YouTube channels.

Tóm tắt tiếng Việt

Shorts Studio là ứng dụng máy tính riêng của chủ kênh, chỉ dùng cho các kênh YouTube của chính chủ kênh. Ứng dụng dùng quyền Google mà chủ kênh cấp để tải video, hẹn giờ, đặt tiêu đề, mô tả, ảnh bìa, bản dịch, đọc và đăng bình luận trên kênh, xem số liệu kênh. Mọi dữ liệu, kể cả token, chỉ nằm trên máy của chủ kênh, không gửi cho bên thứ ba, không bán, không dùng cho quảng cáo. Có thể thu hồi quyền tại myaccount.google.com/permissions.
